# Melbourne_Housing_Regression

Toepassing van Data Analyse en desbetreffend onderzoek en schoonmaak van data, waarna meerdere Machine Learning modellen zijn toegepast om te testen welk model het beste past bij de data.

Deze modellen zijn individueel uitgelicht en geëvalueerd, waarna er verdere diepgang is toegepast op het model dat de beste performance had in de vorm van parameters.

Tenslotte is er ook gebruik gemaakt van Explainable AI om deze modellen inzichtelijk te maken en uit te kunnen leggen.
